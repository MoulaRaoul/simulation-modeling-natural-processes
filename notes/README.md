# Study Notes

This folder is a **living knowledge base** for the skills developed throughout the study of simulation, mathematical modeling, numerical methods, and computational science.

The notes are organized **by competency rather than by course**. A concept may appear in several courses, books, projects, or conversations; instead of duplicating it, we enrich the same note over time.

## Working rule

Whenever a useful concept, method, warning, historical point, mathematical result, programming practice, or modeling insight is learned:

1. identify the competency it belongs to;
2. update the corresponding note;
3. create a new note only when a genuinely new competency appears;
4. link practical implementations to files in `practicals/`, `projects/`, or `notebooks/`;
5. distinguish course-derived ideas from personal extensions or external research.

The goal is to build notes that can be reread independently as small evolving courses.

## Note structure

Each competency note may progressively contain:

- Core idea
- Intuition
- Formal definitions
- Mathematical formulation
- Modeling assumptions
- Common pitfalls
- Worked examples
- Numerical/computational implementation
- Verification and validation
- Historical context
- Applications
- Links to practical work
- Sources and learning history

Not every section is required from the beginning. Notes grow as the corresponding competency grows.
